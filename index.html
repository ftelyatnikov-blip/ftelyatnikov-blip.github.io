GIPIGAP AI Core

Private automation and encrypted backup infrastructure

GIPIGAP AI Core is a private technical service used to automate internal AI workflows and encrypted infrastructure backups.

Google OAuth authorizes owner-requested backup operations and the VPS-AI-Integration connection used by TypingMind to read Google Sheets and create or edit Google Docs.

Google Drive functionality

The system uses authorized Google APIs for encrypted backups, live reading of spreadsheets, and creating or updating owner-requested project documents. Google Sheets access is read-only; document writes use files authorized for the application.

Google user data is not used for advertising, profiling, or sale.

For owner-requested AI analysis, selected content may be processed through TypingMind, OpenRouter and the selected AI model provider, as described in the Privacy Policy.

Access model

This website is informational. The service does not provide public user registration or a public login portal.
